# Skyfire 1943 天气与云雾

本文记录追尾天气表现与遮挡玩法。更新日期：2026-10-02。用户提出并愿意继续探索天气与云雾方向，下面具体机制仍为讨论草案，不是已实现天气系统。

## 当前云层

v0.9 已实现固定云行，与空中目标共用横向观察和纵向升降偏移。高空云不再因海平线缓动而过早停住，固定上下云行使视野保持云的覆盖。

当前云只是背景几何图形，没有功能云体、敌机遮挡、视线丢失、雨、雾、闪电或风力。来源：[云层绘制](../src/rendering/chase_sky.gd)、[飞行偏移](../src/gameplay/chase_flight.gd)。不能把“云已经滚动”记为“天气玩法完成”。

## 两层目标

表现层增强天空、海面和运动感；玩法层改变敌人可见性与瞄准条件。二者分开验证，避免画面好看却难以理解攻击。

| 天气 | 表现草案 | 玩法候选 |
| --- | --- | --- |
| 薄云晴空 | 云边透光、稀薄云隙 | 教学穿云，不强遮挡 |
| 厚云 | 云层明暗和前后关系 | 暂时遮挡敌机，可通过高度选择观察位置 |
| 海雾 | 远岛与船体渐显，近海较清楚 | 用灯光、尾浪与探照灯判断舰船 |
| 阵雨 | 短雨线、海面雨点、远处雨幕 | 优先只做表现，不直接改飞行参数 |
| 雷暴 | 闪电照亮云与轮廓 | 短暂提供位置线索，频率与亮度需验证 |

第一版不让随机风力拖动飞机或改变升降速度，保留已调好的手感。海雾不能使高空重新出现海面；所有天气遵守高度 2.1 以下露海的既有规则。

## 功能云层草案

功能云有明确的高度范围和前后遮挡关系，不只是固定在屏幕上的遮罩。云与敌人共用观察变换，不因玩家转头发生滑动错位。

敌机经过云层的过程拟分为：

1. 进入云边时降低对比，仍能看见轮廓与方向。
2. 进入浓云时机体难辨，但能从发动机光点、曳光或开火闪光得到有限线索。
3. 穿出时渐显，不突然生成一架近处敌机。

遮挡只改变可见性，不改变实际位置、远近阶段、路线或命中规则。预判射击仍可能命中云中目标；云不能变成免伤或删除敌人的条件。

## 玩家利用云层

候选机制是进入云层后敌人停止持续跟踪；已经发射的子弹保留原轨迹，云不吸收攻击。玩家可拉升到云上观察，也可在云下根据最后看到的位置继续接敌。

此机制要与贴海形成选择：低空通过高位攻击，云内摆脱瞄准，云上恢复观察。不能既隐藏敌人又给敌人完美追踪，而玩家没有任何线索。

云层高度、厚度、遮挡时间、敌人丢失与重新获得视线的条件均待验证。追尾目标使用伪三维接近阶段，不可未经实验就把所有敌机坐标解释为真实物理高度。

## 可读性约束

- 浓云中的开火提供可见预警；危险敌弹仍有足够亮度。
- 音效可辅助，但不是唯一提示；不依赖玩家始终开声音。
- 不在浓云里瞬移敌人、偷偷改变攻击类型或刷出贴脸目标。
- 浓雾时不增加普通敌机硬上限，并测试是否应降低同时攻击的数量。
- 道具、机头射击参考和关键高度信息仍可读。
- 闪电不能频繁闪白或依靠闪光才能辨认危险；具体表现强度待测试。

## 关卡候选安排

第一关以薄云介绍穿云表现；第三关王牌战加入局部厚云与可推测的绕出路线；第四关夜海用低空海雾、航灯、尾浪和探照灯；最终关护航突破阶段有阵雨，进入复杂航母部件战后改善视野。

第二关和第五关暂不增加强遮挡，以免地形与天气同时抬高判断负担。完整流程仍以[关卡草案](CAMPAIGN.md)为准。

## 最小验证片段

先试一段短接敌：敌机进入云层，玩家选择预判射击或拉升观察，敌机穿云接近，玩家抓住有效距离命中。分别与无功能云的同一路线对照，不先做全战役随机天气。

验收需要云中坐标与命中结果不变、左右及高空升降无错位、遮挡期间每次危险攻击有线索、隐藏与恢复过程连续，以及玩家能解释为何打中或受伤。仅截图好看不算玩法验收通过。
