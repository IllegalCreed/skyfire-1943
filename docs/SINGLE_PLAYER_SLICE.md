# Skyfire 1943 单人破晓突袭样段

更新日期：2026-10-02。状态：v0.15 已实现，外观与参数待玩家试玩。v0.14 原名“破晓护航”，现按用户反馈改为主动突袭，不保护船队。正式六关、多人、联网及全部成长草案仍未实现。

## 任务与玩家流程

任务是突破敌方拦截线，扫清岛链沿岸火力，击败前来阻截的重型机海鸥。对应追尾突破 → 俯视扫荡 → 追尾决战，每次切换都有电台预告和连续视角桥接。胜利描述与实际击破一致，不再声称护送友军或保护船只；背景船只是环境装饰。

“开始游戏”进入样段，“三视角练习场”保留旧循环刷敌与 1/2/3 快速切换。开发版有八个快速调试入口，包括海鸥。关卡不能用数字键跳段；暂停、改键、手柄输入和默认关闭的显示辅助沿用[设置规则](SETTINGS.md)。

这是单人验证段，不等于[正式第一关草案](CAMPAIGN.md)或六关完成。原约 90 秒是验证目标而非硬时限；取消 Boss 回转等待后，不为了凑时长延迟伤害或增加无敌。实际时长由瞄准、拾取和交战结果决定。

## 道中编排与继承

配置见[关卡导演](../src/gameplay/mission_director.gd)。以下是实现中的待调校参数；时点单位为各段开始后的秒数，不含暂停与镜头桥接。

| 段落 | 时点 / 秒 | 事件 |
| --- | --- | --- |
| 追尾突破，基础段长 28 秒 | 2 / 9 / 16 / 22 | 截击、袭扰、奖励机、单架双发攻击机 |
| 追尾固定补给 | 24 | 一件现有综合补给 |
| 俯视扫荡，基础段长 26 秒 | 1.5 / 7.5 / 13 / 19 | 截击＋袭扰；双截击＋敌炮舰；袭扰＋双发；奖励机 |
| 俯视固定补给 | 22 | 一件现有综合补给 |
| 追尾决战 | 道中完成后 | 海鸥一次接近，保持距离摆动交火，必须实际击破 |

八波空中编排、十一架道中飞机、一艘敌炮舰和一名 Boss，合计十三个目标。导演与练习刷敌器不并行；容量不足等待，不重复派发。前两波追尾首次开火为路线年龄 4.2 秒。普通敌种、有效距离、每组双弹一次伤害和 16～19 帧窗口保持原样，20 帧失效；追尾最多三架空中目标、六枚敌弹、三组我方双弹。

两架奖励机仍击落必掉一件，和每四次击落补给不重复；固定补给不要求击落奖励机。拾取恢复 18 点能量、强化到二级、加 100 分。没有新增 P/E/S/C/R。仅样段俯视中，飞机中心 Y≥84、舰船 Y≥110 且 Y<506 逻辑像素才可交战，避免从 HUD / 操作栏后方攻击或被提前击破。

转场只在旧敌人真实离场 / 被击破后开始，不强删可见普通敌机。能量、火力、分数、波次和未拾取补给保留，最后恢复此前追尾的位置、航向和高度。补给数量、标记和剩余寿命不刷新；新视角重新放到前方 70～160、横向最多 ±180 逻辑像素的航道，不自动给予收益。普通敌机继续持续侧飞，完整轮廓越界后才清除。

## 连续视角桥接

实现见[视角桥接](../src/rendering/view_transition.gd)和[共用追尾背景](../src/rendering/chase_background.gd)。保持 Node2D / 伪三维路线，没有引入 Camera3D。当前只用于关卡的追尾↔俯视两处切换；练习和开发快捷切换仍保持快速响应。

| 项目 | 实现参数 / 行为 |
| --- | --- |
| 预告 | 段落计划结束前 3 秒电台说明下一阶段目的 |
| 镜头桥接 | 2.6 秒，平滑插值 |
| 画面 | 同一架飞机位置、大小与倾斜连续变化，后视 / 俯视渐变；相机轻推拉最多 6% |
| 云层 | 几何云带遮罩，在中段遮住背景交接，起止透明 |
| 逻辑提交 | 进度 50% 时一次切换实际模式和段落 |
| 战斗 | 移动、射击、敌弹和拾取模拟冻结；不扣能量、不产生隐藏攻击 |
| 暂停与取消 | 暂停冻结镜头；重试或返回首页清理全部未完成镜头状态 |

背景与正式画面共用绘制函数；HUD / 文字不参与缩放混合，画面剪裁到 Y=66～506 逻辑像素。飞机在结束点与新视角实际坐标和倾斜一致，正常转场保护期间不因闪烁而在交接帧消失。输入恢复后仍按正常规则移动。

遮罩属于非交战镜头表现，不是功能天气；不会改变飞机物理高度、露海阈值、触海规则、投影或命中。正常追尾的默认 3.3 仍为纯天空，海面仅在 2.1 以下渐入。没有在高空强制露海或用遮挡给敌人无预警攻击。

## 固定距离海鸥

实现见[Boss 模型](../src/gameplay/chase_boss.gd)、[造型](../src/rendering/boss_art.gd)与[任务 HUD](../src/ui/mission_overlay.gd)。双发、宽翼、机鼻与炮位为原创绘制，没有发动机独立部件或跨视角 Boss。

| 参数 | 实现值 / 单位 |
| --- | --- |
| 耐久 | 8 次有效汇聚伤害 |
| 首次接近 | 5.0 秒，深度 220 平滑降到 68 内部单位 |
| 持续距离 | 深度固定为 68，不是米；不再继续靠近或离场 |
| 横向躲避 | 基础幅度上限 ±84 逻辑像素，叠加两组自主摆动 |
| 纵向躲避 | 上限 ±18 逻辑像素 |
| 摆动时钟 | 基础 1.7 弧度 / 秒，叠加 1.83 倍频分量；不是循环出场计时 |
| 损伤 | 半血冒烟，剩余耐久进一步下降时横向幅度最多增加 18% |
| 火力 | 疏双弹，间隔 4.4 秒，半血后 2.8 秒；最多六枚对空敌弹 |
| 首次开火 | 5.8 秒，炮口提前 0.65 秒亮起 |
| 绘制大小 | 基础双发造型的 2.05 倍，不乘入判定容错 |

Boss 就位后持续可受伤；取消 v0.14 每轮三次伤害上限、装甲关闭、侧飞离场和重新生成。只有最初接近为入场阶段，HUD 标注“接近中”；入场结束后仍须原有效距离与第 16～19 帧真实汇聚，不是屏幕重叠或自动锁定。

摆动只由自身时间与损伤决定，不读取玩家输入、相机或已发射子弹，不瞬移闪避。玩家转头不改变 Boss 高度、深度、倾斜或伤害阶段；前进也不会让它在接近结束后持续变大。玩家看向别处时同一 Boss 仍存在，HUD 指示左右方向，停止新的不可见攻击；没有重新把它生成到屏幕中央。已发射可见攻击按正常规则继续运行。

## 胜败与重试

存活并实际击破海鸥才胜利；不是定时击破。Boss 加 2400 分，通关加 1000 分，四舍五入后的每点剩余能量加 10 分，结算一次。显示总分、用时、击破、拾取、能量和加分；胜利冻结模拟，不再受伤或消费能量。

能量耗尽 / 触海为独立失败，R 或按钮从任务开头重置时间轴、Boss、能量、分数与火力，不是检查点 / 存档。设置保留。独立 Boss 调试的击破页与完整样段成绩明确区分。

## 验收与历史调整

[关卡检查](../tests/mission_checks.gd)覆盖编排 / 容量、30/60/144 Hz、暂停、镜头连续和中点提交、补给继承、结束姿态 / 可见性、固定深度 / 双轴摆动 / 长期存在 / 相机独立、原帧命中、取消旧三次上限、胜败与防重复结算。旧普通敌机侧飞和海空规则继续回归。

真实战斗驾驶员只用于 smoke / 捕获，以输入驱动真实路径，没有额外改血、延长保护或强制命中。实际绘制检查包括两次转场逐帧视频和 Boss 状态；验证记录见[开发进度](DEVELOPMENT.md)，主观顺滑度和难度仍需试玩。

v0.14 曾采用“护航”叙事与 Boss 带伤反复回转，但没有真正保护目标，转场也缺少连续感。按用户反馈，v0.15 改为突袭，增加镜头桥接并将 Boss 难度转到固定距离躲避；历史理由见[决策记录](DECISIONS.md)。正式六关 / 多人 / Windows / 实体手柄仍未验证或未实现。
