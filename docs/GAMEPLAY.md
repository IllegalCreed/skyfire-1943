# Skyfire 1943 玩法与机制

本文说明菜单、三视角共同规则、追尾现有手感，以及贴海战术和正式转场的目标。更新日期：2026-10-15；v0.16 增加[我方像素姿态](UNITS.md)，玩法保持 v0.15，基础飞行与汇聚命中沿用 v0.9。

## 游戏目标与参考边界

设计方向是同一架飞机穿越同一场战斗。横版强调航道和攻击布局；俯视强调编队、舰船与区域火力；追尾强调转向、升降、目标远近与汇聚命中。空间表现可以不同，装备成长和敌我识别不能相互矛盾。

主要参考 FC《沙罗曼蛇》《1943》《Sky Destroyer》。弹种选择额外参考《雷电》系列的思路，不把不同平台和不同作品的规则混写。原作依据及限制见[研究记录](DESIGN_PILLARS.md)。

## 主菜单、设置与开发模式

状态：v0.10 已实现。目的：给玩家稳定的启动入口，同时让开发者快速重现已有场景。实现见[菜单](../src/ui/main_menu.gd)与[主流程](../src/main.gd)。

玩家主菜单显示标题、开始游戏、三视角练习场、设置、操作说明与退出。v0.15 的开始游戏进入[单人破晓突袭样段](SINGLE_PLAYER_SLICE.md)，包含追尾 → 俯视 → 追尾、编排波次、现有补给、海鸥验证版和胜败重试，不等于正式第一关完成。练习场保留旧循环刷敌与 1/2/3 切换；样段不能用数字键跳过段落。菜单支持鼠标、方向键 / W/S、Enter 和 Esc；游戏默认 Esc/P 暂停，菜单内模拟停止，设置与未来战役存档分开。

v0.13 的[五类设置](SETTINGS.md)包含显示模式 / 窗口尺寸 / 垂直同步 / 帧率、内部渲染 / 亮度 / 粒子 / 闪屏、总音量 / 音效 / 静音、游戏辅助以及单人键盘改键 / 手柄。显示变更有 15 秒确认和回滚，其余即时生效并在本机保存；未制作背景音乐，不放无效音乐滑块。单人输入与 2P 设备分配分开，后者尚未实现。

v0.12 已实现“机枪辅助准心”和“鱼雷投弹点提示”两个独立开关，默认均关闭。H 只切换机枪准心；鱼雷提示在设置页单独开启，且只有水面可见、投影位置位于原有效绘制范围时才显示。开关不改变机头参考、16～19 帧汇聚窗口、有效距离、鱼雷扫掠碰撞、伤害或能量消耗。v0.13 将机体白色碰撞参考点也设为可选、默认关闭；高度条的 SEA 阈值与低空警告继续保留。

旧设置未记录新版提示配置版本时，第一次读取将两种瞄准提示迁移为关闭；保留音效、音量、全屏和未知配置字段。以后玩家明确开启的新版选择正常保存 / 重载，重开、切视角和返回首页不强制重置。

开发者菜单是开发版首页的额外一项。编辑器运行、带 `developer` 导出特征的应用或显式 `--developer` 启动显示该入口；玩家包默认隐藏，F1 无效，直接调用调试场景也会检查开发模式。开发模式属于调试可见性开关，不作为安全权限边界。开发版飞行中 F1 返回场景选择，也能从暂停菜单进入。

| 调试场景 | 已实现初始状态与用途 |
| --- | --- |
| 横版海岸航道 | 现有断崖、危险边界与横向射击 |
| 俯视岛屿机场 | 现有海岸、舰船与固定侧翼火力 |
| 追尾巡航接敌 | 原有高度 3.3 内部单位，正常接敌 |
| 追尾高空云层 | 高度 4.6 内部单位，检查高空拉升、下降与云滚动 |
| 追尾低空海面 | 高度 1.5 内部单位，增加一艘真实可攻击护航舰；检查岛链、海面与鱼雷 |
| 追尾敌机接近 | 一架敌机从路线年龄 2.6 秒开始，继续正常路线、侧飞与命中判断 |
| 追尾奖励敌机 | 一架金色快机从路线年龄 1.2 秒开始，实际击落必掉补给 |
| 追尾海鸥验证版 | 一次接近后保持距离，验证自主摆动、原汇聚命中与结算 |

每次调试启动重新初始化能量为 100、分数为 0、火力为一级，清理旧战斗对象。R 或暂停菜单的重开会重现所选场景；返回首页后开始游戏重新进入单人样段。未加入无敌、自动锁定或改变触海规则的调试作弊。

默认窗口为 1440×810 像素，内部渲染为 1920×1080 像素，保持 16:9 等比显示。游戏世界与 UI 各放大两倍绘制；飞行、碰撞、弹道和测试继续使用 960×540 逻辑坐标。文字提高采样精度，保留代码绘制、原有几何风格和近远视差。

验收包括两版入口隔离、真实鼠标与键盘导航、暂停与返回、六个场景初始化及重试、设置保存重载、HD 缩放与完整手感回归。菜单主观易用性与大窗口体验仍需玩家试玩反馈。

## 玩家 HUD 信息边界

2026-10-15 用户建议不显示波数，以保留探索感。目标规则：三视角的正常玩家 HUD 均不显示 `WAVE`、当前／总波数、剩余波数或下一波敌种预告；由场景变化、敌人进场和任务演出表达推进。分数、能量、火力等级、必要任务信息、Boss 血条与危险预警仍保留，不把隐藏编排信息误做成隐藏生存信息。本次不调整关卡标题、任务用时或辅助准心规则。

内部波次编号仍用于导演编排、生成、掉落和回归定位；如需在画面查看，仅在开发模式显式开启的调试信息中显示，不作为玩家设置项。显示改动不得影响刷敌顺序、奖励、计分或 Boss 触发，也不删除现有波次变量。

状态：设计方向，尚未实现。[当前 HUD](../src/main.gd)仍绘制 `WAVE %02d / PWR`；后续实施需单独保留火力显示，并检查三视角、练习场、重试与转场均不泄露波数。编排差异与验收见[战役设计](CAMPAIGN.md)。

| 视角 | 操作与攻击 | 当前环境 |

## 追尾飞行与视野

以下为已实现参数，来源：[飞行与投影](../src/gameplay/chase_flight.gd)。高度单位是原型内部坐标，不是米。

| 项目 | 当前值或规则 |
| --- | --- |
| 默认巡航高度 | 3.3 |
| 最高高度 | 6.3，继续按上不会继续升高 |
| 低空警告 | 高度低于 1.05 |
| 触海坠毁 | 高度到达 0.18，战斗无敌和转场保护不能阻止 |
| 海面出现阈值 | 高度低于 2.1，即高度条下方约三分之一 |
| 海面首次进入位置 | 可玩区底边 Y=506，不是包含操作栏的 Y=540 |
| 横向观察滚屏 | 每弧度 600 像素，连续穿过 0 度接缝 |
| 空中纵向滚屏 | `(高度 - 3.3) * 115 + 升降速率 * 12` |

默认巡航和上方约三分之二的高度只见天空。海面在下降时从底部连续展开；远岛随露海渐显。纯天空高度不绘制水面舰船和鱼雷，隐藏舰船不发射不可见攻击。

空中目标、云、远岛和世界对象共享横向观察偏移。我机倾斜不拖动场景；世界对象仍保留真实前进产生的近远视差。云层的纵向偏移与海平线分离，所以高空继续拉升时云仍下移。

## 双弹汇聚与命中

已实现规则来源：[机枪](../src/gameplay/chase_gun.gd)、[实际碰撞路径](../src/main.gd)。

- 双侧炮弹向机头前方的焦点汇聚；辅助标记表示射击参考，不是锁定目标。
- 同时最多三组双弹，一组只有一次伤害消费，不把两条弹流分别计算为两次命中。
- 按 60 Hz 模拟，第 16～19 帧检查双弹中点，第 20 帧失效。
- 六档远近阶段决定判定容错；最远阶段不可命中。
- 远、中、近有效击落分别为 150、200、300 分，实际分档以代码为准。
- 已发射炮弹保留发射时的横向瞄准，纵向跟随当前机体升降；不自动追敌。
- 机枪不伤水面舰船；鱼雷按世界坐标线段扫掠检查水面碰撞。

命中阶段的距离、飞机缩放、轨迹和速度是原创参数。不能把借鉴了原作判定思路写成逐帧忠实复刻。弹种可能改变覆盖与伤害，但不直接取消有效距离约束，见[主炮与弹种](WEAPONS.md)。

## 接敌与侧飞离场

练习场追尾每波一至两架，间隔 6.8 秒；v0.15 单人样段使用独立事件编排，不并行调用练习刷敌器。两者都保留空中上限三架、对空敌弹上限六枚。样段时间轴不等于正式六关编排。

普通敌机从高处小点接近，逐渐下压和放大，再持续加速侧飞。离场最高 1400 逻辑像素 / 秒，高于我方观察滚屏 552 像素 / 秒；完整轮廓加 64 像素余量越界才清除，不按年龄删除。v0.15 海鸥按用户要求成为例外：一次接近后深度固定 68，长期存在、自主双轴摆动，转头不改变其路线 / 阶段 / 倾斜，不重复生成。

来源：[接敌路线](../src/gameplay/chase_encounter.gd)。转头不能改变敌机的纵坐标、远近阶段或自主倾斜动作。

## 贴海战术草案

状态：设计方向是让高度参与战术；按高度避开特定攻击尚未实现。当前低空只是露海、警告与坠毁，不能声称已能躲过高空扫射。

候选攻击有三类：

1. 高空扫射封锁中高空，玩家短暂下降，从弹幕下方通过。
2. 攻击先瞄准高度，开火后冻结瞄准；玩家在预警后俯冲或拉升。
3. 低空散射或水面爆炸碎片反制长期贴海，迫使玩家重新升高。

目标动作循环是高空接敌、读扫射预警、贴海躲避、投雷、拉升脱离。贴海不是无敌区域；已发射的攻击仍有碰撞，低空也有对应威胁。

高度条需要区分可控贴海带和即将触海的危险带，不能所有低飞都只显示同一句警告。安全带阈值、攻击高度范围、预警时间和碰撞表达均待验证，不从现有 0.18 或 1.05 直接推导新的安全判定。

## 正式视角转场草案

练习场保留快速切换。v0.15 样段先预告，在旧敌人实际离场后进行 2.6 秒视角桥接，云带遮罩下于中点切换逻辑；飞机位置 / 大小 / 姿态连续变化。战斗、补给寿命与能量消耗冻结，暂停可冻结镜头，结束姿态与实际飞机一致。保留成长和此前追尾空间状态，正常露海 / 触海规则不变；详见[镜头规则](SINGLE_PLAYER_SLICE.md)。这不是 Camera3D、功能云或六关转场全部完成。

目标战役由任务决定切换，数字键保留在练习模式。转场预告、停止新波次、处理旧弹幕并提供短暂保护。升级、弹种、护盾与库存属于同一架飞机，不能因切换补满或丢失。

跨视角 Boss 必须保持同一身份、已破坏部件和伤害状态。不能照搬当前清空对象逻辑，让航母换视角后恢复完整。叙事不应无故改变地点或把玩家强制带到坠海高度。

## 后续验收

- 贴海能规避明确的高空攻击，但无法规避对应低空攻击；每种情况有可读预警。
- 保险介入由可见库存决定，不把基础触海规则偷偷改成无敌。
- 正式转场不丢装备、不重复补给、不复活 Boss 部件，并维持手感回归测试。
- 云雾遮挡不改变命中坐标、距离阶段或自主路线，见[天气规则](WEATHER.md)。

## 多人目标

用户已确认本地多人和互联网联机方向，并要求单人先完善、多人在后期加入。当前 v0.15 仍为单人。本地横版 / 俯视按同屏 2P 规划，追尾分屏；互联网各自完整画面，均未实现。

多人共享同一场战斗，各自观察不能改变目标真实状态或替另一玩家决定命中。尤其要保持汇聚窗口，并防止一个观察区看不见目标就全局删除。具体输入归属、空间边界、网络与待定合作规则见[多人专题](MULTIPLAYER.md)，不能把本段视为功能已实现。
