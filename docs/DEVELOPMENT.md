## v0.15 镜头与 Boss 验证

2026-10-02 用户反馈 v0.14 转场生硬、未体现护航，并要求海鸥一次接近后停止靠近、通过晃动增加难度，不循环出现。本轮改为破晓突袭，保留既有编排，加入段尾电台预告与 2.6 秒视角桥接；用同一飞机连续位置 / 大小 / 倾斜、云带遮罩和最多 6% 推拉交接背景，逻辑在中点一次切换，不改变物理高度或正常海面阈值。转场冻结战斗、能量和补给寿命，可暂停 / 取消。

海鸥 5 秒接近后深度固定 68，自主双轴摆动，取消旧每轮三次 / 装甲关闭 / 侧飞 / 回转。样段 Boss 为明确例外，普通敌机侧飞与原 16～19 帧窗口仍保护，伤害和成绩只结算一次。转头不改变 Boss 的深度、路线或倾斜；即使不在观察区也不删或重生，不可见时不发起新攻击。

## 新功能的完成标准

功能需有清楚的规则、实际代码、相关回归测试、实际画面或操作验证，以及更新后的实现状态。主观手感仍需试玩，不能自动从 PASS 推断满意。

只改设计文档时不重打游戏包，不替换已有试玩版本；核对本地链接、Markdown 结构、时间和波次合计即可。文档不附带 ROM、反汇编、第三方游戏美术或音乐，也不默认发布到外部服务。
