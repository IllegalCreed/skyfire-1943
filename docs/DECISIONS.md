# Skyfire 1943 设计决策记录

本文保留设计调整的原因，当前玩法与数值以各专题文档为准。整理日期：2026-10-02。历史讨论没有逐条可靠日期时，不补造发生时间；助理提案也不自动记为用户最终确认。

## 定稿飞机结构与姿态稿分离

2026-10-03 用户确认当前认可的是暖象牙 / 冷灰机身、青蓝装饰纹路、中央机身、双发动机舱、连续尾梁和双垂尾的比例风格，同时指出此前追尾拉升 / 俯冲稿的机尾变化及俯冲仍看见机体顶盖。决定先用一套不改变机体结构的临时 3D 参考校验轴向和遮挡，再把单张像素候选放入独立 HTML 设计稿入口；设计稿不自动替换运行时绘制。追尾俯冲要求机腹为主可见面，拉升 / 俯冲仅改俯仰，俯视和侧视姿态规则按 `docs/UNITS.md`，避免把姿态稿误写为玩法或最终贴图。

状态更正（2026-10-14）：此前“精模第一版结构校验已完成”的说法过早。复查发现 v2 仍有翼面叠层、断开的尾撑、悬空窗框和错位标注，不能用渲染成功证明造型正确。用户要求继续优化后，改用同一底图坐标建立 v3，并从实际网格提取俯视投影进行叠合；尾撑连接和网格闭合另作检查。可见轮廓拟合与遮挡区域推定分开，保留 v2 作为旧稿对照。v3 是新的待审候选，不称为用户认可的精模；仍未完成最终贴图 / 像素化，未进入游戏，也不以 HTML 装配代替模型检查。

后续确认（2026-10-14）：用户对 v3 该轮优化反馈“太棒了”，随后要求开始后续工作。以此认可的结构作为姿态基准，使用同一模型刚体旋转生成俯视三张、横版三张、追尾五张，各自保存模型图与像素候选；保留源模型不变，先审姿态与像素表现，不直接替换游戏素材。追尾俯仰不混入滚转，俯冲看到机腹；横版无拉升 / 俯冲姿态。上移左倾 / 下移右倾是本轮展示映射，并非新增已确认控制规则。原生低分辨率、分阶着色和螺旋桨循环用于首轮可读性评审，不冒称最终手绘像素稿。

螺旋桨反馈（2026-10-14）：用户认为清晰桨叶循环过慢，要求动漫式高速旋转白圈，且至少要有两帧闪烁。因此像素候选改用持续淡白桨盘、交替亮暗的外缘与错位弧形残影，不仅加快可辨认桨叶的播放速度。效果定位在原桨轴，正常接受机体遮挡，各视角投影不同；八帧循环及透明度仅为首轮视觉调校。源模型和静态结构稿保留，尚不替换游戏素材；此前提出的方向键连续姿态预览仍为建议，不能算作本轮完成。

## 三视角与原作边界

用户明确要横版、俯视和追尾，并以 FC 版本为主要参考。追尾是伪三维，不因视角名称默认采用三维场景。当前原型沿用 Godot 2D 与原创绘制。

状态：项目方向与已实现基础。机制依据见[研究记录](DESIGN_PILLARS.md)，当前规则见[玩法](GAMEPLAY.md)。

用户反馈屏幕不能只有我机在固定区域移动，低飞还应坠海。v0.2 加入航向、高度和世界滚屏，后续修复双弹焦点、敌机密度、高处接近与实际侧飞离场。

状态：已实现。参数为本原型调校，不因参考原作就声称全部逐帧复刻。

## 海面与云层分别处理高度

用户要求大部分高度为天空，v0.7 把露海移到高度条下方约三分之一。随后左右滚屏反馈引出 v0.8 的共享方位投影；高空拉升时云停住的反馈引出 v0.9 的独立纵向云滚屏。

状态：已实现，横向修正获后续试玩认可。海平线的有界映射不能再作为云层升降偏移，避免重现高空停云。

## 生物机械核心调整为二战岛链

早期连续交战设想包含生物机械核心。后续围绕 1943 与二战背景讨论，形成虚构岛链、雷达、舰船、铁路与航母方案。

状态：当前场景已有岛链样板，六关背景与内容仍是草案，不视为史实战役或已完成剧情。具体内容见[关卡](CAMPAIGN.md)。

## 主炮升级与僚机分开

初提案让二级火力在横版和俯视增加僚机，在追尾只增射速。用户指出跨关卡和跨视角成长需要统一，因此设计调整为 P 强化主炮，僚机独立。

状态：用户提出的统一要求是设计方向；具体三级方案是草案。当前 v0.9 代码仍采用旧二级效果，不能把设计调整记成实现完成。见[成长](PROGRESSION.md)。

## 进攻与保命特殊能力分开

当前 X 在二维模式清弹，在追尾投雷，只有消耗相同，用途并不一致。新的助理提案是三个视角都有进攻重武器与防御清弹，库存规则统一。

状态：讨论草案，未改变按键。共享库存分配和价值预算待确认。

## 弹种与火力等级分开

状态：讨论草案，尚未确认颜色周期、弹种参数或接近锁色。自动追踪与激光不是初稿承诺。见[武器](WEAPONS.md)。

## 关卡环境与成长计分提前验证

2026-10-15 路线图首版把敌机美术样板放在前面，成长与正式关卡在后。用户强调关卡经典机制、环境影响、奖励保险与升级路线同样重要，并指出横版峡谷／雷雨的画面层次和危险表达不足。因此调整为先做关卡与核心系统样板，敌机美术服务于所选片段，不等待整批单位重做才测试玩法。具体先实现岩壁还是雷暴、保险类型和数值仍待确认。

用户要求保留基础补给恢复燃油，沿用当前 18 点能量作为调校起点，不采用此前独立 E 补给 25 点的建议作为默认。现有能量还承担受击与特殊攻击消耗，本次没有拆出新生命条，也没有修改综合补给实现。

旧“散射／穿甲两弹种”草案由用户明确的“散弹／激光／导弹三条升级路线”替换。激光保留光束特色；主武器导弹与当前特殊鱼雷分开，不能把《雷电》不同版本的主副武器规则混为同一来源。三级、配色、是否制导、独立换装与升级道具仍为建议。沙罗曼蛇式僚机需在三个视角真实参与攻击，追尾不能只换成射速加成；共享齐射预算的具体可行性待实验。见[武器专题](WEAPONS.md)。

用户另要求分数和排行榜。新增[计分专题](SCORING.md)，区分已经存在的原型分数与未实现的榜单，建议本地纪录先行、Steam 好友／全球榜后接。高分技巧不作为基础燃油的唯一来源，合法保险不默认取消资格；开发模式、接关、难度、人数与规则版本需有清晰边界。状态：方向已记录，机制与上线方案仍待确认；本轮没有接入外部服务或修改游戏。

## 多语言和发行宣发贯穿开发阶段

2026-10-15 用户要求把多语言、后期 Steam 上架与宣发纳入路线图。语言涉及三视角 HUD、菜单、警告与未来分屏，不能等 UI 全部定型后才处理；因此先规划文本资源、术语、字体和长文案验证，再随稳定内容翻译与审校。最初建议简体中文、繁体中文、英语；随后用户要求约 12 种，并明确纳入日语、西语、葡语、意大利语、法语、俄语，替换原来的三语首批建议。

约 12 种的清单沿用简中／繁中／英语，额外建议德语／韩语／波兰语补足；新增三种及西语西班牙版本／葡语巴西版本仍待确认。简中与繁中分别计数，地区翻译分别审校，不靠重复勾选未制作的地区版本凑数。中英文技术小样继续先行，但不代表缩减语言目标；配音另行决定。当前尚未实现翻译或语言切换。

Steam 商店页、公开 Demo、正式发售和联网 SDK 接入分开安排。原发布专题的顺序容易被理解为全部等待多人完成，本次明确商店准备与宣发从可展示 Demo 阶段并行，合作开发仍后置。新品节只作为候选，依据 Demo 质量和届时资格选择；推广、预算、账号、付款、媒体联系和正式发布均需用户确认。补入发售后反馈与修复安排，但不承诺未经确认的 DLC 或更新周期。状态：计划已补齐，尚未实现或对外执行，详见[路线图](ROADMAP.md)和[发行宣发](RELEASE.md)。

## 在关卡中学习并补齐完整战役流程

2026-10-15 路线图评审后，用户明确本作操作简单，应在关卡中学习，不需要单独新手教学。因此不增设教程关、强制弹窗或操作解锁任务，通过正常编队、补给出现顺序、命中反馈和危险预告建立理解；保留必要按键说明与默认关闭的准心／投弹点。三视角 HUD 设计仍保留，不与教程系统绑定。

用户认可音乐音效与战斗反馈，以及后续难度重玩、保存兼容、可读性、素材流程和测试的补充方向。路线图将其分配到小交付与验收，不把认可方向等同一次性开工；M1 建议拆小，M2 准备陌生玩家试玩，邀请、外包和采购仍需另外确认。已有合成音效与设置不称为完整音频制作，现有闪屏开关也不代表全部效果已可减弱。

用户随后要求保留并完善已部分形成的简单故事，把各关串起来；每关结束先结算再进入下一关，通关后有排行榜。沿用虚构岛链突袭与海陆补给／旗舰主线，补充关间因果，不改回护航或增加复杂分支。单关分项、战役累计与全通总评共用真实结算，末关奖金不重复计入；装备跨关继承，存盘、检查点和榜单资格仍分别确认。当前只有样段胜败页与重试／返回，下一关、全通总评和榜单未实现；六关数量与数值仍是草案。

本轮只同步[路线图](ROADMAP.md)、[战役](CAMPAIGN.md)、[计分](SCORING.md)及相关专题，没有修改运行时、制作音乐、发出邀请或发布新包。

## 隐藏玩家波数并强化编排差异

2026-10-15 用户建议不显示 `WAVE` 数以保留探索感，并要求不同波次有区分度、敌人可以组合出现。正常玩家 HUD 不预报当前／总波数、剩余波数或下一波敌种；内部波次状态继续服务生成、奖励与测试，仅在开发模式显式启用调试信息时展示。必要的攻击、环境与 Boss 入场预警保留，不以探索感为由制造无预警伤害。

新鲜度来自敌人职责、队形、路线、时机与环境的组合，优先用已有敌种制作有节奏的固定编排，再验证有限变体；不是只换颜色、加耐久或增加数量。现有样段已含混合敌机及飞机／舰船组合，后续重点是让它们产生不同的应对选择，同时保留低压和补给机会。经典游戏参考需明确平台和关段，不混写规则或复制素材。

已将信息边界和编排验收同步到[玩法](GAMEPLAY.md)、[战役](CAMPAIGN.md)与[路线图](ROADMAP.md)。状态：设计要求，当前游戏仍显示 `WAVE`，本轮未修改 HUD、导演、敌种参数或试玩包，也未改动六关草案的波次合计；具体组合与时序仍待试玩确定。
