# Skyfire 1943 — 设计原则

本文保留原作研究和原型迭代的历史取舍。当前规则及新增设计从[开发文档总目录](README.md)进入；历史段落不能代替现行方案。更新日期：2026-10-02。

## 目标

同一架飞机穿越同一场战斗，空间规则改变，但武器反馈、状态和敌我识别保持一致。参考对象均以 FC / 红白机版为主，不能用同名街机版代替其机制。

## 原作依据与本次选择

### 沙罗曼蛇 FC

横版与纵版关卡交替；胶囊推进强化选择条；Option 延迟跟随我机轨迹，强化集中火力，也允许通过移动展开攻击。地形直接影响生存。画面有生物组织、火焰、机械设施等不同区域。

原型选择横版通道与跟随火力，暂未做强化选择条、激光/波纹互斥和原作生命规则。横版不能只有开阔背景与换向射击，必须有可读的空间约束。

参考：[任天堂 FC 版 VC 说明书](https://www.nintendo.co.jp/data/software/manual/man_tbzj.pdf)、[FC 原始说明书图文](https://setsumei.cloudfree.jp/famicom/salamander/salamander.html)。

### 1943 FC

俯视海空战；能量会随时间与受击消耗，特殊攻击也以能量换取防御。FC 版有能力配点与成长，不应误写成街机双人规则。编队、补给、舰船与大型目标提供不同攻击任务。固定侧翼飞机与沙罗曼蛇的跟随 Option 不是同一种行为。

原型选择俯视编队、舰炮目标、能量和清弹攻击，并把能量暂时作为三视角的共同生存资源。此统一规则是原创设计取舍，不是声称另外两款原作也采用能量制。能力配点、武器计时、大型舰船部位破坏尚未实现。

参考：[Capcom NES 版说明书扫描](https://www.thegameisafootarcade.com/wp-content/uploads/2017/02/1943-The-Battle-of-Midway-Game-Manual.pdf)。

### Sky Destroyer FC

追尾伪 3D；机枪对空、鱼雷对海；左右涉及转向，上下涉及升降。目标远近影响奖励，海面与天空决定战斗空间，并非普通俯视游戏换相机。原作还有航向环绕、低空撞海、不同时间段和基地目标。

0.1 错把追尾控制实现成固定画面内的二维位置，这是空间规则上的偏差。0.2 改为连续回旋的航向、前进的世界位置与独立高度；相机投影跟随我机，世界目标不会因转出画面而立刻被删除。云与太阳具有固定方位，海面纹理具有世界坐标，转向引起一致滚动。上下升降带动垂直视野，最高空只见天空，触海直接坠毁。

0.3 修正第二个误解：原版普通敌机不是与独立三维子弹做碰撞，而是在双弹年龄至少 16 帧时，检测两侧屏幕坐标的中点与敌机基准点的水平／垂直距离。原始弹道生命周期让正常有效窗口只有第 16～19 帧。六个接近阶段的阈值分别为 (0,0)、(2,2)、(4,3)、(6,6)、(7,7)、(8,9)，使用严格小于比较；最远阶段不可击中，远／中／近得分为 150／200／300。该结论来自 PRG CRC32 为 219CE59D、CHR CRC32 为 86E2067A 的日版 ROM 反汇编，以及未修改机器码的受控 RAM 测试，不是录像推测。关键判定入口为 $EDEB，阈值表为 $E20B。

据此，机枪改为原创屏幕空间汇聚弹道，第 20 帧清除，最多三组。准心不再投影水平世界射线，而是与当前射击的汇聚点使用同一个机头参考；旧弹保留发射时的水平瞄准位置，随升降调整垂直位置，不自动追敌。原版没有常驻圆圈准心，因此本版提供可按 H 隐藏的小辅助标记，绝不把标记重叠当成无延迟命中。对空编队按可见瞄准区投放，接近后曲线倾斜离场；距离阈值、屏幕缩放和轨迹均为原创参数。敌机世界坐标表达伪 3D 的投影位置与接近层级，不宣称是物理高度。

0.4 根据试玩继续修正：0.3 在准心附近刷敌、每 3.3 秒投放 3～5 架、存活 18 秒，容易积累高密度目标；绕出触发还依赖当前视野下的深度，玩家转头会改变敌机的动作与大小。改为每波 1～2 架、间隔 6.8 秒、最多三架，从画面上方逐渐下压放大，再侧向离场。当时单架约 5.6～6.9 秒按定时回收，下一次试玩发现了这一回收条件的问题。

原版受控代码运行也确认了这种空间表达：普通路线之一从屏幕基准 Y=24 起步，依次下压到 Y=51、100、179；另一条从 Y=43 起步，先小幅上扬再下压。原版 $EC1B 的渲染前处理减去同一个水平滚屏量，测试中不同大小阶段都随滚屏 8 像素左移 8 像素，纵坐标不变。它不是转头就改变目标相机深度的普通透视相机。因此，本版对空目标改用环绕的二维空域坐标：自主路线只随时间推进，远近阶段只随接近进度变化，玩家朝向只施加统一横向偏移。天空、空中敌弹和空中补给使用同一偏移，倾斜只作用在我机和准心，不拉动目标锚点。水面与鱼雷仍使用原来的世界投影；两套坐标通过明确的对象类型分开处理。

0.5 根据同向追踪反馈修正退场：旧路线的侧移最多 510 像素，接近结束后即停止移动，并在固定年龄删除。玩家同向转头时会把敌机留在画面里，看到它突然消失。现在接近后持续自主侧飞，以 800 像素／秒²加速，最高 1400 像素／秒，高于我方转向空域滚屏的上限 552 像素／秒；倾斜平滑增加到约 64°。横向位移不再随接近进度封顶，只在整架机体越过左右边界、中心额外留出 64 像素余量时删除，不使用兜底年龄强删。测试覆盖两侧持续追踪、双机延迟出场、航向接缝、反向和可见老目标，维持原有密度限制。上述速度、角度和路线均为本原型的原创手感调校，不声称复刻原版数值。

仍用二维投影，不使用三维场景；滚屏、我机高度与水面鱼雷保留世界坐标，鱼雷碰撞仍用三维线段扫掠。保留对空／对海分工与近距离奖励。速度与短惯性尚待调校，不宣称与原版逐帧一致；日夜循环、失控坠落中的射击、原作残机规则以及逐像素还原没有实现。原版 ROM 与整份反汇编仅保留在忽略的本地研究目录，不加入 Git 或导出包。

参考：[Taito FC 版说明书扫描](https://gamemanual.midnightmeattrain.com/entry/%E3%82%B9%E3%82%AB%E3%82%A4%E3%83%87%E3%82%B9%E3%83%88%E3%83%AD%E3%82%A4%E3%83%A4%E3%83%BC)、[扫描件存档](https://archive.org/details/sky-destroyer-tfc-sd-4500-fc-jp-manual-600-dpi)、[FC 实机录像](https://www.youtube.com/watch?v=Jcx08iU9fs0)（可观察到高空画面仅剩天空）。录像用于核对视觉行为，不足以证明当前数值已经匹配原作。

## 结合，不是堆叠

早期候选结构包含追尾截击、俯视攻击舰炮、横版进入生物机械核心。后续已转为虚构二战岛链的六关草案，生物机械核心不属于当前战役。仍保留共享飞机、能量与火力，并由任务解释视角变化的方向；当前关卡方案见[关卡与 Boss 设计](CAMPAIGN.md)。

切换必须提示新规则、保护玩家，并处理旧弹幕的空间语义。0.1 直接清除敌机、子弹和未拾取补给，保留能量、分数、升级状态和波次；这是安全的实验接缝，正式关卡需进一步设计，不能把清弹切换当成无成本逃生技能。

## 0.6 场景与飞机表达

画风已得到试玩认可，保留深蓝海面、青绿我方、暖红敌方、琥珀提示与原创几何轮廓，不改成写实贴图或复制原作像素。以虚构的二战太平洋岛链为场景底色：追尾用黎明海天、固定方位远岛和岸上设施；俯视用海岸机场、机库、码头与背景船队；横版用断崖、防空危险区和多层远山。场景比敌机和炮弹低对比，始终先画在战斗对象下面。远岛共用天空方位滚屏，浮标使用海面世界投影；上升到海面完全出视野时不绘制岛屿。横版的上方危险线表达防空火网，下方表达岩壁，沿用原碰撞函数，不凭背景建筑新增隐形碰撞。

我机采用原创双发轮廓；敌方分别是窄翼截击机、宽翼袭扰机和大型双发攻击机，三视角分别绘制，不把俯视图旋转后当侧视图。侧视敌机只水平镜像，座舱和垂尾不能翻到机腹。加入座舱、发动机、螺旋桨、翼面线、尾翼涂装等细节，但远距离省略细节，保留可读小轮廓。识别标记为原创颜色与几何图案，不采用历史阵营徽记。僚机改为小飞机、适当拉开间距，延迟跟随与固定侧翼这两种语义不变，发射位置与实际机体一致。

敌种不只是皮肤：袭扰机有自主横向摆动，双发机慢速接近、追尾耐久为两次有效命中、较长间隔的双弹；截击机保留基础参数。所有类型仍从高处接近、同量滚屏、持续侧飞并完全越界后删除，不让类型变化破坏 v0.5 修复。追尾密度仍最多三架、敌弹最多六枚。大型轮廓不自动放宽原有汇聚命中半径。敌船增加炮舰和武装运输船轮廓，运输船开火较疏。

本版只落实场景与敌种样板，不等于已做六关战役；机场、码头和背景船队还没有攻击／护航目标逻辑，敌方炮舰和运输船才是可攻击目标。剧情、阶段转场和多部位 Boss 需要另行实现与验证。

## 0.7 海面出现的高度范围

0.6 默认高度为 3.3／6.3，海平面却在画面 Y=210，导致中间高度也有大半屏海面。根据试玩反馈，海面应只在高度条下方约三分之一出现，而不是仅最高空才消失。露海阈值设为 6.3／3=2.1；在此高度地平线恰好位于可玩区底部 Y=506，而非包含操作栏的画布底部 Y=540。继续下降时地平线连续上移，接近触海高度 0.18 时达到 Y=80。阈值之上的地平线使用连续指数缓动，保持在画面之外，也避免无限上移使所有天空装饰都消失。此映射是按本原型反馈调校，不声称取自原版数值。

海平面不再充当对空纵向滚屏量。敌机、对空敌弹、空中补给保留原有 `(高度-3.3)*115 + 升降速率*12` 的纵向偏移，准心与弹道继续使用机头参考，机体升降、警告和坠海规则也不变。远岛在露海后随可见海面高度渐显，纯天空范围隐藏水面舰船与鱼雷画面；舰船不可在未露海时隐身开火。水面世界位置、魚雷碰撞和既有伤害仍按原方式模拟，不通过移动整个场景或修改目标距离来伪造海面位置。高度条增加 SEA 刻线便于判断进入海空交战区。

## 0.8 海空统一转向滚屏

0.7 的云、太阳、远岛与对空目标已经按方位角统一滚屏，但舰船、海面纹理、浮标与鱼雷仍采用水平针孔透视：焦距为 380，而空域滚屏为每弧度 600 像素；水面投影的中心还取自受倾斜影响的我机屏幕位置。这会造成转向速度不一致、船被机翼带着走，以及视野边缘滚动加速。此前所谓两套坐标只是对象类型分工，没有保证它们共用同一相机，试玩发现了这一视觉不连续。

现在全部对象的水平投影都使用 `480 + wrap(世界方位 - 观察方向) * 600`，空域目标也调用同一函数。云和远岛作为无限远背景保持固定方位；世界对象从飞机后方 6 单位的追尾观察点求方位。垂直投影和舰船大小按距该观察点的平面距离计算，不再按当前观察方向的点积计算，所以仅转动视野不会改变船的高度或大小。我机倾斜只影响我机和机头准心，不再拖动场景。

观察点仍随飞机在世界中前进和回旋，因此近船、浮标与海面纹理仍有随距离变化的合理移动视差，不强行把所有物体钉在同一张背景板上。投影逆变换同步更新，近船先完整越过可玩区底边再转入身后。鱼雷的世界运动和扫掠碰撞、对空目标的自主接近／侧飞、汇聚窗口和海面高度阈值保持原有规则。这是本原型的原创协调方案，不声称照搬原版相机数值。

## 0.9 高空云层纵向滚屏

0.7 为了保持上方三分之二的高度只见天空，把海平线在高空缓动到画面外 Y=606；0.8 的云层纵坐标仍写成 `海平线-80-分行偏移`，因此飞机虽然继续升高，云也会随海平线过早停住。高度 4→5 时旧云层只移动不到 2 像素，不足以表达仍在拉升。

现在云层使用独立的固定空域坐标，与对空目标共用 `(高度-3.3)*115 + 升降速率*12` 的纵向偏移；高空拉升／下降都会继续滚动。固定方位的云扩展为间距 380 像素的上下云行，在全部允许高度和朝向下保留可见云。云行是真实固定坐标，不是把一朵仍可见的云传送回屏幕另一端；完整离开可玩区才剔除绘制。画风、水平滚屏、对空准心和射击、海面阈值与飞行控制保持不变。太阳继续作为远处海平线装饰，不改海空出现范围。

云层不增加无输入时的虚假漂移；松手后仍按原控制响应稳定下来，达到真实最高高度 6.3 后才停止继续向上滚屏。此方案是按试玩反馈修正本原型，并非声称取自原版云层数值。

## 里程碑

1. 0.1 三视角基础实验；0.2 修正追尾航向、视野滚动、高度与坠海；0.3 修正机头准心、双弹汇聚与命中窗口；0.4 修正敌机密度、高处接敌和统一空域滚屏；0.5 修正同向追踪下的实际侧飞退场；0.6 扩展岛链场景、三视角飞机细节和敌种；0.7 修正海面在高度条下方三分之一渐入；0.8 统一海空转向滚屏；0.9 修正高空拉升时云层停滞。当前版本。
2. 连续交战：90 秒关卡，编排过渡点，保留同一任务与目标的身份。
3. 阅读性：明确追尾深度提示、低空风险、敌弹预警、碰撞边界；根据试玩调整速度和密度。
4. 再定工具链：衡量 Godot 的迭代与分发成本后，决定是否用于正式制作。

不得复用原作美术、音乐、敌人设计或关卡布局。所谓致敬必须来自玩法理解，而不是未经授权的资产搬运。
