# Skyfire 1943 设置与单人控制

更新日期：2026-10-15。实现基线：v0.13 初版，后续单人样段继续沿用；新增的音画与可读性要求仍为计划。目的：提供正常游戏的五类设置，不把尚无实际功能的选项放入可调列表。默认值来自[字段配置](../src/ui/settings_defaults.gd)，界面见[设置菜单](../src/ui/main_menu.gd)。

## 分类与实现参数

| 分类 | 已实现项目 | 默认值 / 单位 |
| --- | --- | --- |
| 显示 | 窗口 / 全屏、窗口尺寸、垂直同步、帧率上限 | 窗口 1440×810 像素；同步开；上限 60 帧 / 秒 |
| 画面 | 内部渲染清晰度、亮度、爆炸粒子、闪屏、帧率显示 | 高清 1920×1080 像素；100%；完整粒子；闪屏开；帧率显示关 |
| 音频 | 总音量、音效音量、静音、测试音效 | 总音量 100%；音效 75%；不静音 |
| 游戏辅助 | 机枪准心、鱼雷投弹点、我机碰撞参考点、底部提示、失焦暂停 | 三种参考关；操作提示开；失焦暂停开 |
| 控制 | 输入方式、手柄选择、摇杆死区、追尾上下反转、震动、键盘改键 | 自动键盘＋手柄；自动选设备；死区 18%；不反转；震动开 |

窗口尺寸可选 1280×720、1440×810、1920×1080 像素，超过屏幕可用区域时等比适配。全屏使用当前桌面尺寸，全屏时窗口尺寸项不可调。垂直同步依赖显示后端实际支持；帧率上限可选 30 / 60 / 120 / 144 帧每秒或不限，是最大值而非最低性能保证。

内部渲染独立于物理窗口，可选标准 1280×720、清晰 1600×900、高清 1920×1080 像素。游戏及菜单仍使用 960×540 逻辑坐标；不改变投影、命中容错、60 Hz 模拟、双弹汇聚时间或视差。亮度范围 80%～120%，步长 5 个百分点，仅调整游戏画面。粒子可关闭、精简或完整，只改变爆炸显示，不改变模拟或随机数消耗。闪屏只控制受击 / 特殊攻击的颜色叠加，不改变伤害。

两个音量范围均为 0%～100%，步长 5 个百分点，总音量与音效音量相乘。测试按钮使用同一音效和音量路径。当前没有配乐，背景音乐标注“暂未制作配乐”，不提供无效滑块。难度、语言、战役存档、多人设备槽、分屏布局、网络与 Steam 尚无对应系统，不提供伪功能选项；随相关玩法开发再补齐。

## 操作、保存与显示保护

可从主菜单或暂停菜单进入，左侧分类、右侧选项。鼠标、键盘及默认手柄菜单导航可用。偏好跨三视角、重开和调试场景共用，不是战役存档，也未接入 Steam 云存档。

音频、画面、辅助与控制即时生效并保存到 `user://settings.cfg`。缺失新字段用默认值；保存前读入旧文件，保留未知字段和已有偏好。继续沿用 v0.12 提示迁移：旧配置缺少 `play/aim_guides_version=2` 时，将机枪 / 鱼雷提示一次性关闭，此后明确开启的选择正常重载。完整格式标记为 `meta/settings_version=3`，不重置其他旧偏好。

显示分类先修改草稿，点击“应用显示设置”后进入确认页。15 秒内“保留并保存”才持久化；超时、“还原”或 Esc 恢复旧显示偏好，窗口模式下也恢复原实际尺寸。取消不保存预览值。内部渲染不切换操作系统显示模式，即时生效。每页可恢复该分类默认；键盘子页只恢复按键，不重置设备与死区。其他分类变更不会把手动调整的窗口拉回预设尺寸。

机枪准心、鱼雷投弹点、我机碰撞参考点默认均关闭、独立可选。H 只切换机枪提示；鱼雷提示仍受水面可见性和投影范围约束；碰撞点不是完整判定边界。高度条、低空警告、触海和真实命中不受显示辅助影响。

失焦暂停默认开，仅在单人实际飞行中触发；失焦释放已记录的键盘状态，避免回来后继续移动。未来联网暂停另行设计，不直接暂停整个房间。反转上下只作用于追尾，横版 / 俯视不反转。

## 单人键盘与手柄

实现见[输入路由](../src/input/player_controls.gd)。自动模式将键盘及一个选定手柄映射到同一架飞机；仅键盘忽略手柄游戏输入；手柄优先在没有选定可用设备时回退键盘。Esc 始终可以打开 / 返回菜单。未连接设备明确提示；震动测试在无设备、不支持或关闭震动时禁用。

| 行为 | 默认主键 | 备用键 / 手柄 |
| --- | --- | --- |
| 上、下、左、右 | W、S、A、D | 方向键；左摇杆 / 十字键 |
| 射击 | 空格 | Z；A |
| 特殊攻击 | X | B |
| 暂停 / 继续 | Esc | Esc / P；Start |
| 重开 | R | Y |

点击主键后按新键；与其他行为的主键或备用键冲突时拒绝并提示，Esc 取消。Enter、数字键 1/2/3、F1、M、H、Tab 保留给菜单和原型快捷操作。备用键保留，操作说明和底部提示随主键更新。当前不支持组合键、鼠标射击映射或手柄按钮自定义。

摇杆径向死区为 5%～40%，步长 1 个百分点；死区外幅度重映射到 0～1，合成方向长度不超过 1。设备可自动或指定。实际受击与测试均为 0.15 秒震动，弱 / 强幅度 0.25 / 0.45（0～1 无量纲），仅在设备支持时调用。

这次是单人控制，不是本地 2P；多玩家分配、同键盘双区域、分屏、联网尚未实现，见[多人目标](MULTIPLAYER.md)。实际手柄机型、实体死区和震动需连接真实设备验收，模拟事件通过不代表硬件兼容通过。

## 依赖与验收

### 后续音画与可读性计划

按路线图随实际内容接入，不在本轮添加空选项：

- 配乐制作后提供独立音乐音量，与音效共同验收静音、暂停、重试、转场及结算。高密度开火和爆炸不能掩盖警告，降低某类音量不影响战斗事件。
- 核对实际尺寸的字号、字幕、三视角 HUD 及多语言换行；道具和武器兼用图标／轮廓，不只依赖颜色。后期复测追尾分屏。
- 当前闪屏开关只覆盖受击／特殊攻击叠加，不能声称已覆盖未来雷电、激光或现有桨盘明暗变化。后续统一检查闪烁与镜头晃动，提供适用的减弱方式，保留旋转动感和危险预告，不改变判定。
- 不设置独立教程入口或强制教学；保留必要按键说明和可选底部提示，玩家通过正常关卡学习。机枪准心和鱼雷投弹点继续独立、默认关闭。

### 已有回归与后续验证

依赖现有主流程、原生 Control 菜单、合成音效及本机配置文件。[设置回归](../tests/settings_checks.gd)覆盖分类恢复、实际音量 / 亮度 / 渲染尺寸、显示确认 / 超时还原、按键捕获 / 冲突 / 取消、控制器事件 / 死区 / 反转、无设备回退及所有字段保存重载；另保留[提示回归](../tests/aim_guides_checks.gd)及全部战斗检查。

实际引擎截图覆盖五分类、改键、确认页、1280 / 1920 像素渲染和可选 HUD。导出应用还需原生输入、本机显示切换、签名与 ZIP 验证，结果见[开发进度](DEVELOPMENT.md)。易用性和控制手感仍待用户试玩，不从自动测试推导已认可。
