# Skyfire 1943

一个原创三视角射击游戏的可玩研究原型。名字中的 Sky 致敬 FC《Sky Destroyer》，fire 呼应 FC《沙罗曼蛇》，1943 致敬 FC《1943》。不使用原作 ROM、图像、音乐或关卡。

游戏代码在 `src/`，菜单在 `src/ui/`，输入在 `src/input/`，场景在 `scenes/`，回归测试在 `tests/`，开发工具在 `scripts/`，设计在 `docs/`。应用与截图放 `outputs/`，引擎与缓存放 `work/`，这两个目录不上传。详见[仓库说明](docs/REPOSITORY.md)；开发者与 Codex 开始任务前阅读[AGENTS.md](AGENTS.md)。

## 先玩，不用先学引擎

当前原型使用 Godot 4.7.2 的 **2D 绘制 + 伪 3D 透视**，没有 Camera3D 或 3D 场景。开发阶段负责提供直接打开的 Mac 应用，玩家不需要安装 Godot。引擎是否适合长期开发，仍要由原型的手感和迭代体验决定。

本地玩家版位于 `outputs/Skyfire 1943 v0.16.app`；开发版位于 `outputs/Skyfire 1943 v0.16 Developer.app`。双击应用，点击“开始游戏 · 破晓突袭”或按 Enter。默认窗口 1440×810 像素、内部渲染 1920×1080 像素，可在设置中调整。旧版保留用于对比。

本轮 v0.16 接入我方定稿模型烘焙的像素飞机与连续姿态：先进入“三视角练习场”，按 1 / 2 / 3 切换。俯视左右移动倾斜；横版上下移动倾斜、前后保持；追尾支持倾斜、抬头 / 压头及斜向组合。松手逐帧回正，白桨盘独立高速闪动。射击、碰撞和飞行规则不变。

玩家首页包含开始游戏、独立三视角练习场、设置、说明和退出。开发版另有八个快速场景，包括海鸥验证版。鼠标、方向键 / W/S、Enter / Esc 导航；手柄 A 确认、B 返回。五类设置保存于本机，显示变更需在 15 秒内确认。详见[设置与控制](docs/SETTINGS.md)。

破晓突袭是主动突破任务，不保护船只。追尾 → 俯视 → 追尾的两次转场有电台预告、2.6 秒镜头桥接、连续飞机姿态和云带遮罩，期间不交战或扣能量。海鸥只接近一次，到深度 68 后停止靠近、持续双轴摆动并可连续受伤，不离场或重生，不再限制每轮三次伤害。实际击破才通关，胜败 / 整段重试 / 现有补给保留，准心默认关闭，原汇聚帧不变。

单位图鉴位于 `outputs/skyfire-unit-handbook.html`，八个实际单位 / 二十张引擎视图，包括海鸥验证版；完整部件海鸥和其他正式 Boss / 岸防另标草案。图片和数据内嵌，支持筛选和对比，无需联网。详情见[单位专题](docs/UNITS.md)。

图鉴另有“我方战机设计稿”入口：本地 v3 模型的十一种关键姿态分别查看模型图和大尺寸像素预览，可播放 / 暂停高速白桨盘。v0.16 已从同一模型另烘焙实际游戏尺寸的 99 个姿态、792 帧，接入我机和僚机；设计稿的大图不是直接缩放贴进游戏。

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 横版/俯视移动；追尾左右回旋、上下升降 |
| Space / Z | 持续射击（按住） |
| 1 / 2 / 3 | 仅练习场切换横版 / 俯视 / 追尾；关卡不可跳段 |
| X | 横版、俯视：清弹冲击；追尾：水面鱼雷，消耗 15 能量 |
| P / Esc | 打开暂停菜单、继续；菜单中 Esc 返回 |
| R | 重新开始 |
| M | 静音切换 |
| H | 切换追尾机枪准心（默认关闭）；鱼雷投弹点在设置中独立开关 |
| F1 | 开发版返回开发者场景菜单；玩家版无效 |

以上是默认键位，主键可以重绑。单人手柄左摇杆 / 十字键移动，A 持续射击，B 特殊攻击，Start 暂停，Y 重开；死区、设备选择、追尾上下反转和震动可调。手柄路径已接入并通过事件模拟，当前没有真实手柄型号的兼容性验收。

能量缓慢消耗，受击和特殊武器也会消耗能量。每击落四个目标产生一个补给，金色快速奖励敌机击落必掉一件金色 B 补给；拾取恢复 18 点能量、强化到二级并加 100 分。我机白色碰撞参考点默认关闭，可在游戏辅助中开启，不代表完整碰撞边界。

## 0.16 目前有什么

- 我方像素帧动画：横版 / 俯视各 9 档滚转，追尾 9×9 滚转 / 俯仰组合，每姿态 8 档桨盘相位。固定画框、最近邻采样，不用两张图透明叠化，也不修改飞行 / 射击参数。

- 破晓突袭：主动突破叙事、编排波次、连续转场、固定距离摆动海鸥、胜败结算与重试。练习场仍为旧循环玩法，正式六关未完成。

- 五类实际设置：显示确认 / 还原；清晰度、亮度、粒子和闪屏；总音量和音效；游戏辅助；单人改键、手柄、死区、反转与震动。当前无配乐，音乐项明确标注未制作。

- 机枪辅助准心、鱼雷投弹点提示分别可选，默认均关闭。设置保存在本机，重开不改变选择；旧版提示配置一次性迁移为双关闭，保留其他设置。

- 三视角敌我飞机强化为二战活塞动力轮廓：我方双发双尾撑，敌方短鼻截击、长鼻袭扰、双发攻击和金色奖励机。炮口、尺寸和命中规则保留。
- 敌船区分护航炮舰与武装运输船，加入舰桥、烟囱、炮塔、货舱与吊货桅杆；甲板细节仍是外观，岸防静态炮台尚未实现。
- 练习场金色奖励敌机每五波取代第一架；单人样段固定编排两次。它飞行较快，击落必掉补给，保留调试入口与离线图鉴。

- 玩家主菜单与开发版专属场景菜单；暂停和飞行结束都能返回首页。开发场景重开回到其预设初始状态。首页的“三种视角”是说明文字。
- 持久化音效、音量、全屏、机枪准心与鱼雷投弹点设置；1920×1080 像素绘制，菜单文字提高采样精度。游戏仍使用 960×540 逻辑坐标和原有 60 Hz 模拟。

- 横版：断崖防空航道，远山分层滚动、岩壁层理、地面建筑与上方防空危险区；保留原有上下危险边界、横向射击和升级后的轨迹跟随僚机。
- 俯视：岛屿海岸、机场跑道、机库、码头与船队背景；可攻击的护航炮舰、武装运输船和固定侧翼辅助火力。机场与背景船队目前只是场景，没有攻击／保护任务判定。
- 追尾：保留连续回旋、世界滚屏、升降、低空警告和触海坠毁。机枪改成双侧炮弹向机头前方汇聚，最多同时三组；每组只在第 16～19 帧用双弹中点判定普通敌机命中，第 20 帧消失。六档远近阶段决定判定容错，最远初始阶段不能命中，远／中／近击落分别为 150／200／300 分。机枪辅助准心默认关闭，可按 H 切换，跟随机体升降和倾斜；鱼雷投弹点另设开关，默认关闭；它不是锁定框，也不代表屏幕对齐就会立即命中。鱼雷仍使用水面世界坐标与扫掠碰撞。
- 追尾敌机从画面上方的小点出场，逐渐下压、放大，再大角度倾斜、加速向侧边逃离。侧飞最高 1400 像素／秒，超过我方最快转向滚屏的 552 像素／秒，持续同向追踪也会被甩开。接近路线结束后仍继续侧飞，不按固定年龄删除；整架飞机越过左右边界并留出 64 像素余量后才清除。每波 1～2 架、间隔 6.8 秒，硬上限 3 架。敌机、对空敌弹、空中补给与天空方位使用统一的二维空域滚屏，左右移动不会再改变敌机的高度、远近阶段或绕出动作。轨迹与节奏是原创调校，不复制原作轨迹表。火力升级提高追尾射击频率，不增加平行子弹。
- 共享我机、能量、分数和武器等级；切换清理旧空间的威胁，有短暂无敌和提示。
- 开始界面、音效、暂停、失败、重试。
- 三视角的飞机分别绘制侧面、俯视、前／后轮廓，加入座舱框、翼面分段、尾翼、发动机、螺旋桨和原创识别涂装；远处省略细节，保持轮廓。僚机由圆点改成小飞机，间距匹配轮廓，仍分别采用延迟跟随与固定编队。追尾增加固定方位的远岛、岸上设施和世界坐标浮标，海天滚动规则不变。
- 三种实际敌机：轻型截击机（快速接近、单发）、袭扰机（横向摆动、单发）、双发攻击机（慢速稳定接近、疏双弹，追尾需两次有效命中）。三者都有独立轮廓、速度、耐久和射击间隔，不是单纯换色。追尾仍每波 1～2 架、最多 3 架，敌弹最多 6 枚；大型机并未放宽既有汇聚命中规则。两种敌船分别显示炮位／货舱，运输船开火较疏。
- 追尾海面只在高度条下方约三分之一出现：默认巡航高度 3.3／6.3 为纯天空，高度降到 2.1 以下才从游戏区域底部露海，越低海面越大；高度条的 SEA 刻线表示这个阈值。远岛渐显，纯天空高度隐藏水面舰船与鱼雷的画面，隐藏舰船不发射不可见攻击。海平面映射与对空纵向滚屏分开，因此不改敌机、敌弹、补给、机头准心或汇聚射击的既有移动关系。升降速度、低空警告和触海坠毁不变。
- 追尾天空、远岛、敌机、船、浮标、海面纹理和鱼雷统一按方位角滚屏，每弧度 600 像素；我机倾斜不再拖动海面和船。水面对象按距追尾观察点的实际平面距离显示高度和大小，单独转动视野不再让船突然变大或改变纵坐标；观察点随飞机前进与回旋仍有正常的近景视差。水面碰撞继续使用世界坐标，旧版对空汇聚窗口和侧飞离场不变。
- 追尾云层的纵向位置不再绑定高空趋于不动的海平线，改为与对空目标共用升降滚屏。高空拉升时云继续下移，下降时上移；新增固定的上下云行，让原有云滑出画面后仍有其他云进入，不在屏幕内部突然回绕。只有达到实际最高高度才停止继续向上滚动。左右滚屏、机头准心、海面阈值与飞行控制不变，太阳仍作为远处海平线的装饰。

## 明确还没有

这是研究原型，不是完整游戏或原作忠实复刻。0.2～0.9 修正空间与命中，0.10～0.13 增加菜单、造型、奖励和设置，0.14～0.15 完善单人关卡样段，0.16 接入我方像素姿态。基础战斗仍沿用 0.9，参数为原创调校。没有正式六关、完整部件 Boss、战役存档、双人、互联网联机、统一的敌方像素素材、日夜循环或正式平衡；沙罗曼蛇胶囊选择条和 1943 局外配点也未实现。

数字键自由切换仅用于练习场。样段之后的成长和正式六关需继续确认，早期生物机械核心不属于当前二战岛链方向；详见[关卡设计](docs/CAMPAIGN.md)和[开发进度](docs/DEVELOPMENT.md)。

## 开发与验证

Mac 上运行 `bash scripts/bootstrap-macos.sh` 会把官方引擎和导出模板放进 `work/tools`，不会安装到系统应用目录。首次下载约 1.4 GB；玩家不需要运行它。

```sh
work/tools/Godot.app/Contents/MacOS/Godot --path .
bash scripts/test.sh
ruby scripts/check-docs.rb
bash scripts/build-macos.sh
```

自动测试覆盖三种模式的战斗与对象清理、机枪／鱼雷目标区分、2D 扫掠命中、补给、受击无敌、失败与重启、键盘切换与暂停、跨视角状态保留。追尾检查包含世界滚屏、航向接缝、低空坠海，以及全部高度／爬升／倾斜组合的机头准心位置、双侧弹道终点、16～19 帧窗口、20 帧失效、慢帧不漏判、六档判定边界、150／200／300 分路径、三组射击上限、敌机侧向离场和 H 切换。模拟固定为 60 Hz，并检查 30／60／144 Hz 显示刷新率产生一致的模拟结果。构建脚本检测日志中的运行错误，不能只凭进程退出码或 PASS 字样认定成功。

0.4 增加 120 秒不射击／反复转头的密度检查、上方出场与持续下压、不同远近敌机的等量横移、转头不改变纵坐标／阶段／倾斜、空域 360° 接缝、敌弹与补给共用滚屏、空中补给可拾取和鱼雷跳过空域目标的检查。

0.5 增加左右满速同向追踪（单／双机、不同初始航向）、从出场就转向、中途反向、0° 接缝、旧版到期时仍可见不删除，以及 20 秒老目标与部分机体贴边仍不删除的回归检查。正常追踪应在 10 秒内真实越界，这只是测试断言，不是游戏中的强制寿命。

0.6 增加自然波次覆盖三种敌机与两种敌船、三视角不同移动速度、实际双发机两次汇聚命中、疏双弹只占剩余敌弹槽、各机型自主摆动／统一滚屏、全部机型两侧同向追踪与轮廓完全越界检查。旧版消失回归样本固定为原截击机，不随波次机型变化而丢失。

0.7 增加巡航／上方三分之二纯天空、露海阈值、601 个高度采样的连续单调映射、阈值两侧位置与滚动速度连续、低空海面扩展、对空纵向滚屏保持原参数，以及近处舰船不能突入纯天空画面或隐身开火的检查。

0.8 增加两侧转向、视野中央／边缘、多种距离海空等量横移、倾斜不拖景、转动视野不改变船的纵坐标／大小、投影及距离逆变换、海面对象 360° 接缝、背后目标不可见、前进视差与近船完全越过底边，以及实际鱼雷显示线和世界扫掠命中的检查。

`--capture-flight` 渲染巡航/右转/高空/低空/坠海五个状态；`--flight-demo` 自动演示右转、爬升、下降和坠海，可配合 Godot 的 `--write-movie` 录制实际引擎画面。截图命令仅用于测试，不改变玩家操作规则。

当前截图保存到 `outputs/screenshots-v0.16/`，旧版保留。`--capture-mission` 以真实战斗模拟生成关卡 / Boss / 结算；`--capture-transitions` 与 `--capture-boss-motion` 分别生成 1280×720 镜头和静止相机 Boss 的逐帧图，用于短视频核对。`--capture-settings`、`--capture-menu`、`--capture-guides` 保留，其他空间检查参数也继续使用。默认关卡画面 1920×1080，标准清晰度 1280×720；图鉴仍为二十张 768×480 视图。不分发原作 ROM、图像或音乐。

编辑器或本地源码运行默认显示开发者入口，独立玩家包默认隐藏；显式传入 `--developer` 可以开启开发模式。构建脚本一次生成两版应用、ZIP 与图鉴，并检查源码、导出包、签名及压缩完整性。只更新图鉴时可执行 `bash scripts/build-unit-handbook.sh`，不需要重打应用。

若只更新独立设计稿且已有 `outputs/unit-art-v0.16/units.json` 和对应单位图，可运行 `ruby scripts/build-unit-handbook.rb` 重新内嵌 `outputs/unit-designs/catalog.json` 的图片与动画帧，无需重渲染游戏单位。设计稿深链接使用 `#design=chase-dive-model` 等条目 ID；所有图片仍可离线浏览。

`--capture-player-animation` 通过真实飞行输入捕获三视角的倾斜、回正、升降和斜向动作，输出到 `outputs/player-animation-v0.16/`。原创运行时图集在 `assets/aircraft/player/`，构建不依赖 Blender 或本地研究目录；美术再烘焙方法与输入依赖见[资源说明](assets/README.md)。

Mac 构建使用本地 ad-hoc 签名，未做 Apple 公证；本机原地构建可运行不代表互联网下载后的 Gatekeeper 分发流程已经验证。尚未在 Intel Mac、Windows 或其他机器上测试。
