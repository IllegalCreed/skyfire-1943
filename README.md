# Skyfire 1943

一个原创三视角射击游戏的可玩研究原型。名字中的 Sky 致敬 FC《Sky Destroyer》，fire 呼应 FC《沙罗曼蛇》，1943 致敬 FC《1943》。不使用原作 ROM、图像、音乐或关卡。

## 先玩，不用先学引擎

当前原型使用 Godot 4.7.2 的 **2D 绘制 + 伪 3D 透视**，没有 Camera3D 或 3D 场景。开发阶段负责提供直接打开的 Mac 应用，玩家不需要安装 Godot。引擎是否适合长期开发，仍要由原型的手感和迭代体验决定。

本地新版位于 `outputs/Skyfire 1943 v0.2.app`，双击后按 Enter 开始。旧版保留用于对比。

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 横版/俯视移动；追尾左右回旋、上下升降 |
| Space / Z | 持续射击（按住） |
| 1 / 2 / 3 | 横版 / 俯视 / 追尾 |
| X | 横版、俯视：清弹冲击；追尾：水面鱼雷，消耗 15 能量 |
| P / Esc | 暂停、继续 |
| R | 重新开始 |
| M | 静音切换 |

能量缓慢消耗，受击和特殊武器也会消耗能量。每击落四个目标产生一个补给，拾取可恢复能量并升级辅助火力。白色小点是我机命中位置提示（不是完整的可视碰撞边界）。

## 0.2 目前有什么

- 横版：滚动通道、地形伤害、横向射击、升级后的轨迹跟随僚机。
- 俯视：海面、敌机编队、可攻击的舰炮目标、固定侧翼辅助火力。
- 追尾：独立航向、世界坐标与高度。左右持续回旋，云、太阳、海面纹理与目标随视野一起滚动；航向绕回 360°，不受屏幕边缘限制。上下升降改变整个垂直视野，最高空海面完全移出画面。低空警告后触海会坠毁，不受受击无敌保护。机枪与鱼雷沿发射时的世界航向飞行，命中不依赖屏幕重叠。
- 共享我机、能量、分数和武器等级；切换清理旧空间的威胁，有短暂无敌和提示。
- 开始界面、音效、暂停、失败、重试。

## 明确还没有

这是手感实验，不是完整游戏，也不是三款原作的忠实复刻。0.2 修正了追尾的固定屏幕平移问题，但转向速度、惯性、升降速度等是待试玩的原创参数，并未声称逐帧复刻 FC 原作。暂时没有完整关卡、Boss、存档、双人、手柄、像素美术资产、日夜循环和正式平衡。沙罗曼蛇的胶囊选择条、1943 的局外能力配点也没有实现。

数字键自由切换仅用于比较三套规则，不表示正式游戏一定允许随时切换。下一步建议做一段连续交战：追尾接敌 → 俯视拆舰炮 → 横版进入核心。

## 开发与验证

Mac 上运行 `bash scripts/bootstrap-macos.sh` 会把官方引擎和导出模板放进 `work/tools`，不会安装到系统应用目录。首次下载约 1.4 GB；玩家不需要运行它。

```sh
work/tools/Godot.app/Contents/MacOS/Godot --path .
work/tools/Godot.app/Contents/MacOS/Godot --headless --path . -- --smoke
bash scripts/build-macos.sh
```

自动测试覆盖三种模式的战斗与对象清理、世界空间命中、机枪/鱼雷目标区分、2D 扫掠命中、补给、受击无敌、失败与重启、键盘切换与暂停、跨视角状态保留。新增追尾检查：世界滚动方向、居中的跟随机体、松手保留航向、连续回旋、360° 接缝、爬升垂直滚动、低空警告、触海不受无敌保护和重开恢复安全高度。构建脚本检测日志中的运行错误，不能只凭进程退出码或 PASS 字样认定成功。

`--capture-flight` 渲染巡航/右转/高空/低空/坠海五个状态；`--flight-demo` 自动演示右转、爬升、下降和坠海，可配合 Godot 的 `--write-movie` 录制实际引擎画面。截图命令仅用于测试，不改变玩家操作规则。

Mac 构建使用本地 ad-hoc 签名，未做 Apple 公证；本机原地构建可运行不代表互联网下载后的 Gatekeeper 分发流程已经验证。尚未在 Intel Mac、Windows 或其他机器上测试。

设计依据和取舍见 [设计原则](docs/DESIGN_PILLARS.md)。全部画面由原创几何图形生成，音效由代码合成。Godot 引擎使用 MIT 许可，随应用附带其许可说明。
