# Skyfire 1943

一个原创三视角射击游戏的可玩研究原型。名字中的 Sky 致敬 FC《Sky Destroyer》，fire 呼应 FC《沙罗曼蛇》，1943 致敬 FC《1943》。不使用原作 ROM、图像、音乐或关卡。

游戏代码在 `src/`，场景在 `scenes/`，回归测试在 `tests/`，开发工具在 `scripts/`，设计在 `docs/`。应用与截图放 `outputs/`，引擎与缓存放 `work/`，这两个目录不上传。详见[仓库说明](docs/REPOSITORY.md)；开发者与 Codex 开始任务前阅读[AGENTS.md](AGENTS.md)。

## 先玩，不用先学引擎

当前原型使用 Godot 4.7.2 的 **2D 绘制 + 伪 3D 透视**，没有 Camera3D 或 3D 场景。开发阶段负责提供直接打开的 Mac 应用，玩家不需要安装 Godot。引擎是否适合长期开发，仍要由原型的手感和迭代体验决定。

本地新版位于 `outputs/Skyfire 1943 v0.9.app`，双击后按 Enter 开始。旧版保留用于对比。

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 横版/俯视移动；追尾左右回旋、上下升降 |
| Space / Z | 持续射击（按住） |
| 1 / 2 / 3 | 横版 / 俯视 / 追尾 |
| X | 横版、俯视：清弹冲击；追尾：水面鱼雷，消耗 15 能量 |
| P / Esc | 暂停、继续 |
| R | 重新开始 |
| M | 静音切换 |
| H | 显示／隐藏追尾模式辅助汇聚标记，不改变命中规则 |

能量缓慢消耗，受击和特殊武器也会消耗能量。每击落四个目标产生一个补给，拾取可恢复能量并升级辅助火力。白色小点是我机命中位置提示（不是完整的可视碰撞边界）。

## 0.9 目前有什么

- 横版：断崖防空航道，远山分层滚动、岩壁层理、地面建筑与上方防空危险区；保留原有上下危险边界、横向射击和升级后的轨迹跟随僚机。
- 俯视：岛屿海岸、机场跑道、机库、码头与船队背景；可攻击的护航炮舰、武装运输船和固定侧翼辅助火力。机场与背景船队目前只是场景，没有攻击／保护任务判定。
- 追尾：保留连续回旋、世界滚屏、升降、低空警告和触海坠毁。机枪改成双侧炮弹向机头前方汇聚，最多同时三组；每组只在第 16～19 帧用双弹中点判定普通敌机命中，第 20 帧消失。六档远近阶段决定判定容错，最远初始阶段不能命中，远／中／近击落分别为 150／200／300 分。辅助汇聚标记跟随机体升降和倾斜，可按 H 隐藏；它不是锁定框，也不代表屏幕对齐就会立即命中。鱼雷仍使用水面世界坐标与扫掠碰撞。
- 追尾敌机从画面上方的小点出场，逐渐下压、放大，再大角度倾斜、加速向侧边逃离。侧飞最高 1400 像素／秒，超过我方最快转向滚屏的 552 像素／秒，持续同向追踪也会被甩开。接近路线结束后仍继续侧飞，不按固定年龄删除；整架飞机越过左右边界并留出 64 像素余量后才清除。每波 1～2 架、间隔 6.8 秒，硬上限 3 架。敌机、对空敌弹、空中补给与天空方位使用统一的二维空域滚屏，左右移动不会再改变敌机的高度、远近阶段或绕出动作。轨迹与节奏是原创调校，不复制原作轨迹表。火力升级提高追尾射击频率，不增加平行子弹。
- 共享我机、能量、分数和武器等级；切换清理旧空间的威胁，有短暂无敌和提示。
- 开始界面、音效、暂停、失败、重试。
- 三视角的飞机分别绘制侧面、俯视、前／后轮廓，加入座舱框、翼面分段、尾翼、发动机、螺旋桨和原创识别涂装；远处省略细节，保持轮廓。僚机由圆点改成小飞机，间距匹配轮廓，仍分别采用延迟跟随与固定编队。追尾增加固定方位的远岛、岸上设施和世界坐标浮标，海天滚动规则不变。
- 三种实际敌机：轻型截击机（快速接近、单发）、袭扰机（横向摆动、单发）、双发攻击机（慢速稳定接近、疏双弹，追尾需两次有效命中）。三者都有独立轮廓、速度、耐久和射击间隔，不是单纯换色。追尾仍每波 1～2 架、最多 3 架，敌弹最多 6 枚；大型机并未放宽既有汇聚命中规则。两种敌船分别显示炮位／货舱，运输船开火较疏。
- 追尾海面只在高度条下方约三分之一出现：默认巡航高度 3.3／6.3 为纯天空，高度降到 2.1 以下才从游戏区域底部露海，越低海面越大；高度条的 SEA 刻线表示这个阈值。远岛渐显，纯天空高度隐藏水面舰船与鱼雷的画面，隐藏舰船不发射不可见攻击。海平面映射与对空纵向滚屏分开，因此不改敌机、敌弹、补给、机头准心或汇聚射击的既有移动关系。升降速度、低空警告和触海坠毁不变。
- 追尾天空、远岛、敌机、船、浮标、海面纹理和鱼雷统一按方位角滚屏，每弧度 600 像素；我机倾斜不再拖动海面和船。水面对象按距追尾观察点的实际平面距离显示高度和大小，单独转动视野不再让船突然变大或改变纵坐标；观察点随飞机前进与回旋仍有正常的近景视差。水面碰撞继续使用世界坐标，旧版对空汇聚窗口和侧飞离场不变。
- 追尾云层的纵向位置不再绑定高空趋于不动的海平线，改为与对空目标共用升降滚屏。高空拉升时云继续下移，下降时上移；新增固定的上下云行，让原有云滑出画面后仍有其他云进入，不在屏幕内部突然回绕。只有达到实际最高高度才停止继续向上滚动。左右滚屏、机头准心、海面阈值与飞行控制不变，太阳仍作为远处海平线的装饰。

## 明确还没有

这是手感实验，不是完整游戏，也不是三款原作的忠实复刻。0.2 修正了固定屏幕平移；0.3 修正双弹命中与机头准心；0.4 进一步把敌机的自主路线与玩家滚屏拆开，修正密度、出场位置和横向移动造成的投影异常；0.5 修正同向追敌时的定时消失，改为持续大幅侧飞和实际越界退场；0.6 保留原有几何画风，扩展架空二战岛链场景、飞机细节和敌机种类；0.7 按试玩反馈把海面可见区移到高度条下方三分之一，不改对空射击手感；0.8 统一海空转向滚屏，修正水面旧透视与我机倾斜造成的错位；0.9 修正高空拉升时云层过早停住。原版没有常驻圆圈准心，本版的小辅助标记可关闭。弹道曲线、分辨率缩放、距离分档、敌机路线和飞行速度仍是原创参数，未声称逐帧复刻。暂时没有完整关卡、Boss、存档、双人、手柄、像素美术资产、日夜循环和正式平衡。沙罗曼蛇的胶囊选择条、1943 的局外能力配点也没有实现。

数字键自由切换仅用于比较三套规则，不表示正式游戏一定允许随时切换。后续候选是先做约 90 秒连续交战样段，验证同一任务的转场、补给和 Boss。正式六关采用虚构二战岛链草案，早期生物机械核心不属于当前战役；具体方案与待确认问题见[关卡设计](docs/CAMPAIGN.md)和[开发进度](docs/DEVELOPMENT.md)，尚未启动实现。

## 开发与验证

Mac 上运行 `bash scripts/bootstrap-macos.sh` 会把官方引擎和导出模板放进 `work/tools`，不会安装到系统应用目录。首次下载约 1.4 GB；玩家不需要运行它。

```sh
work/tools/Godot.app/Contents/MacOS/Godot --path .
bash scripts/test.sh
ruby scripts/check-docs.rb
bash scripts/build-macos.sh
```

自动测试覆盖三种模式的战斗与对象清理、机枪／鱼雷目标区分、2D 扫掠命中、补给、受击无敌、失败与重启、键盘切换与暂停、跨视角状态保留。追尾检查包含世界滚屏、航向接缝、低空坠海，以及全部高度／爬升／倾斜组合的机头准心位置、双侧弹道终点、16～19 帧窗口、20 帧失效、慢帧不漏判、六档判定边界、150／200／300 分路径、三组射击上限、敌机侧向离场和 H 切换。模拟固定为 60 Hz，并检查 30／60／144 Hz 显示刷新率产生一致的模拟结果。构建脚本检测日志中的运行错误，不能只凭进程退出码或 PASS 字样认定成功。

0.4 增加 120 秒不射击／反复转头的密度检查、上方出场与持续下压、不同远近敌机的等量横移、转头不改变纵坐标／阶段／倾斜、空域 360° 接缝、敌弹与补给共用滚屏、空中补给可拾取和鱼雷跳过空域目标的检查。

0.5 增加左右满速同向追踪（单／双机、不同初始航向）、从出场就转向、中途反向、0° 接缝、旧版到期时仍可见不删除，以及 20 秒老目标与部分机体贴边仍不删除的回归检查。正常追踪应在 10 秒内真实越界，这只是测试断言，不是游戏中的强制寿命。

0.6 增加自然波次覆盖三种敌机与两种敌船、三视角不同移动速度、实际双发机两次汇聚命中、疏双弹只占剩余敌弹槽、各机型自主摆动／统一滚屏、全部机型两侧同向追踪与轮廓完全越界检查。旧版消失回归样本固定为原截击机，不随波次机型变化而丢失。

0.7 增加巡航／上方三分之二纯天空、露海阈值、601 个高度采样的连续单调映射、阈值两侧位置与滚动速度连续、低空海面扩展、对空纵向滚屏保持原参数，以及近处舰船不能突入纯天空画面或隐身开火的检查。

0.8 增加两侧转向、视野中央／边缘、多种距离海空等量横移、倾斜不拖景、转动视野不改变船的纵坐标／大小、投影及距离逆变换、海面对象 360° 接缝、背后目标不可见、前进视差与近船完全越过底边，以及实际鱼雷显示线和世界扫掠命中的检查。

0.9 增加高空 4→5 时同一实际绘制云朵下移 115 像素、全部纯天空高度／升降速率／完整航向的云覆盖、真实 60 Hz 升降方向与逐帧连续、与冻结敌机共用纵向偏移、松手稳定、真实最高高度停止，以及云层横向航向接缝不变的检查。

`--capture-flight` 渲染巡航/右转/高空/低空/坠海五个状态；`--flight-demo` 自动演示右转、爬升、下降和坠海，可配合 Godot 的 `--write-movie` 录制实际引擎画面。截图命令仅用于测试，不改变玩家操作规则。

`--capture-aim` 渲染中立、爬升、倾斜、关闭辅助标记四个状态到 `outputs/screenshots-v0.9/aim`。`--capture-encounter` 渲染上方出场、接近、近处、侧边离场和左右滚屏到 `outputs/screenshots-v0.9/encounter`。`--capture-pursuit` 用实际 60 Hz 飞行模拟左右同向追踪，渲染倾斜、超过旧删除时间、掠过边缘、彻底离场四个状态到 `outputs/screenshots-v0.9/pursuit`。`--capture-art` 用引擎渲染三个场景样板和三视角飞机轮廓表到 `outputs/screenshots-v0.9`，其中敌机位置是固定的展示样本，不代表实际刷敌队形。`--capture-altitude` 渲染巡航、阈值上下、低空和最高空八个高度状态到 `outputs/screenshots-v0.9/altitude`，核对海面只在下方三分之一渐入。`--capture-scroll` 冻结敌机自主路线，以实际 60 Hz 飞行绘制低空左右转向的逐段对照到 `outputs/screenshots-v0.9/scroll`，便于比较云、岛、飞机、近远两船与海面纹理的运动。`--capture-sky` 以实际飞行绘制高空中立、拉升、最高空、下降、松手和高空右转到 `outputs/screenshots-v0.9/sky`，核对高空云层继续滚动且不会全部滑出视野。原版 ROM 只用于本地分析，没有随游戏、版本库或测试器分发；代码不嵌入原版弹道表、图像或音乐。

Mac 构建使用本地 ad-hoc 签名，未做 Apple 公证；本机原地构建可运行不代表互联网下载后的 Gatekeeper 分发流程已经验证。尚未在 Intel Mac、Windows 或其他机器上测试。
